# 自定义检测任务流程指南

V6 支持自定义新任务流程，但自定义的是“已注册检测器的组合、顺序、启停和失败策略”，不是让用户在前端自由编写新算法。

## 示例：车辆月度运行合规检测流程

1. 基础数据质量检查
2. 轨迹数据质量检查
3. 过站数据质量检查
4. 长期无运行证据检测
5. 轨迹规律性异常检测
6. 轨迹与过站一致性检测
7. 风险等级映射
8. 证据绑定
9. 结果入库

## 示例：区县月度运营合规综合检测流程

1. 基础数据质量检查
2. 站点设置异常检测
3. 车辆轨迹规律性异常检测
4. 车辆轨迹与过站一致性检测
5. 线路站点数量异常检测
6. 有件无车辅助核验
7. 异常摘要生成

## 说明

新增检测算法仍由开发人员实现 `AbnormalDetector` 并注册为 Spring Bean；配置管理页面只负责把已注册检测器加入流程。
